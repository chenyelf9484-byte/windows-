# 实际支持范围与待验证项目

当前为 0.1.0 开发版本。Python 核心测试通过不等于 Office/WPS 实机验收通过。

| 格式 | 当前实现 | 验证状态 |
|---|---|---|
| DOCX | WordprocessingML/DrawingML 段落文本、页眉页脚、常见文本框 | 自动化结构与内容测试；实际 Word/WPS 待测 |
| XLSX | sharedStrings、inlineStr、str 文本单元格，公式单元格跳过 | 自动化测试；实际 Excel/WPS 待测 |
| PPTX | DrawingML 段落、常见表格文本，母版/版式可选 | 自动化测试；实际 PowerPoint/WPS 待测 |
| TXT/MD/LOG | 分行匹配，保留编码及换行 | 自动化测试 |
| CSV/TSV | 字段匹配、正确重新引用和转义 | 自动化测试；引号风格可能规范化 |
| DOC/XLS/PPT | Windows COM 转为现代格式，在扫描得到的转换副本上修改，再写回原格式 | 桥已实现，未 Windows 实测；可能改变排版或丢失旧版特有功能 |
| WPS/ET/DPS | 显示明确未支持原因 | 原格式写回暂未开放 |
| PNG/JPEG/BMP/TIFF | 可选 OCR、整行区域重绘、整张图片替换 | macOS 中文样图 OCR 和绘制通过；Windows 打包及真实业务图片待测 |
| PDF/宏文档/加密文档 | 暂不支持 | 不修改 |

## 保留策略和边界

- 现代 Office 只替换命中 XML 节点，样式、关系、动画等未修改部件保留原始字节。
- 现阶段只支持常见 Transitional OOXML；Strict OOXML、非 UTF-8 XML 和特殊命名空间应单独验证。
- Excel 图表、批注、页眉页脚、绘图形状文字暂不替换；只处理文本单元格及可选嵌入图片。
- Word 域代码不替换；域计算结果可能被 Word 下次更新域时重新生成。修订、内容控件、特殊对象需人工复核。
- 默认跳过 PPT 母版和版式；可选扫描。幻灯片备注中常规 DrawingML 文字也会扫描。
- 一条文本勾选项对应段落/片段、单元格、文本行或 CSV 字段，该项内全部命中一起修改，不是单个关键词出现的独立勾选。
- 同一 XML 段落内跨 run 匹配，跨段落、显式换行和制表不匹配。
- 若某部件文本节点无法可靠对应，会跳过该部件并报告；其他部件仍可处理。请查看注意信息。
- 只检测常见 Office 锁文件；实际文件占用最终由操作系统写入权限决定，不能保证识别所有程序占用。
- 一批任务不是全批事务；已保存文件在取消后保留，取消在当前文件结束时生效。
- 暂停/继续仅对当前会话有效；不支持退出后恢复任务。
- 路径扫描默认单文件不超过 200MB；OOXML 解压内容不超过 512MB、30000 项。
- 不跟随符号链接；不同磁盘和同名根目录输出可能冲突，冲突文件拒绝覆盖并记录失败。

## 图片

- 图片开关默认关闭，不加载 OCR；OCR 版安装包会更大。
- 命中默认不勾选，必须查看预览并确认。OCR 可能错字或漏字。
- OCR 框是整行范围：以指定纯色填充再绘制替换后的整行文本，并非复杂背景修复。
- 支持输入像素坐标修正选区，指定中文字体、字色、背景色和整图替换。
- 不支持多帧 TIFF；旋转 EXIF 在编辑时会归一化。修改图片可能重编码并移除元数据。
- 同一文档中的字体和颜色统一；更改时其他已确认图片将取消勾选，要求重新确认。
- 图片预览会组合显示同图已勾选项及当前项；同张图片多行或重叠选区仍需检查组合效果。

## 发布验收清单（尚未完成）

1. 干净 Windows 10 64 位电脑，解压后双击 EXE，含中文和空格路径。
2. 无 Python/Office 的机器上测试核心现代文档与 TXT 批处理。
3. Word/Excel/PowerPoint 和 WPS 实际打开修改后文件，无修复提示，编辑并保存。
4. 有/无 COM 接口、有/无 Office、WPS 不同安装版本下的旧版格式验证。
5. OCR 包断网运行，中文模型、字体、前后预览、整图替换及多张图片批量保存。
6. 文件只读、占用、磁盘满、权限不足、取消、大目录、多盘同名输出。
