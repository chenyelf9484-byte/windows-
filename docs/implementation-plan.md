# 开发与验证记录

按已确认方案开始实现。交付入口为 Windows EXE，当前开发机为 macOS。

1. 规则匹配：精确、可选忽略大小写、较长词优先、不连锁。
2. 格式读写：文本与 OOXML 原始节点局部修改，保留其他 ZIP 部件。
3. 保存事务：内容 SHA-256 检查、临时文件校验、备份、覆盖及副本排他创建。
4. 界面：扫描路径、规则、结果三个页签，后台任务和暂停取消。
5. OCR：可选依赖，默认关闭；整行白底重绘与整图替换，必须预览确认。
6. Windows 兼容桥：Office/WPS COM 只打开临时副本；旧版文档往返转换。
7. 自动测试：跨 run、共享字符串、公式保留、编码、CSV、选择修改、目录排除及文件变化。
8. 打包：Windows Python 3.11 x64 + PyInstaller onedir；核心版与 OCR 版分开构建。

发布前仍需在真实 Windows 10、Word/Excel/PowerPoint、WPS 中完成手工兼容验证。
GitHub 工作流仅提供配置，尚未推送或运行，不代表已有 EXE 构建产物。
